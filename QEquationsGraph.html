What is a Quadratic Function?

Simple Definition:

A quadratic function is a mathematical function where the highest power of the variable is 2. It creates a U-shaped curve called a parabola.

f(x) = ax² + bx + c

Where:

  • a = coefficient of x² (cannot be zero)
  • b = coefficient of x
  • c = constant term

🌟 Real-Life Example: Basketball Shot

When you shoot a basketball, the ball follows a parabolic path. The height of the ball at any moment can be described by a quadratic function:

h(t) = -16t² + 20t + 6

Where:

  • h(t) = height of the ball in feet
  • t = time in seconds after the shot
  • -16 = gravity pulling the ball down
  • 20 = initial upward velocity
  • 6 = initial height (your hand height)

Opening Direction: Upward or Downward?

Simple Rule:

The direction a parabola opens depends on the coefficient a in the equation f(x) = ax² + bx + c

😊 Opens UPWARD (Happy Face)

a > 0

When a is positive:

  • The parabola looks like a U or a smile
  • The vertex is the minimum point
  • The function has a lowest value

Example: f(x) = 2x² + 3x - 1

(a = 2, which is positive)

☹️ Opens DOWNWARD (Sad Face)

a < 0

When a is negative:

  • The parabola looks like an upside-down U or a frown
  • The vertex is the maximum point
  • The function has a highest value

Example: f(x) = -3x² + 4x + 2

(a = -3, which is negative)

🌟 Real-Life Example: Profit Function

Business Scenario: A company's profit based on the price of their product:

P(x) = -50x² + 400x - 200

Where x is the price in dollars.

Why it opens downward (a = -50): There's an optimal price point. If you price too low, you don't make enough per item. If you price too high, no one buys! The vertex shows the perfect price for maximum profit.

The Vertex: The Turning Point

Simple Definition:

The vertex is the highest or lowest point on a parabola. It's where the parabola changes direction.

Finding the Vertex

For a quadratic function f(x) = ax² + bx + c, the vertex coordinates (h, k) are found using:

h = -b/(2a)

Then substitute h back into the function to find k:

k = f(h) = ah² + bh + c

Key Points About the Vertex:

  • The x-coordinate of the vertex is at x = -b/(2a)
  • The axis of symmetry passes through the vertex (x = h)
  • If a > 0: vertex is the minimum point
  • If a < 0: vertex is the maximum point

📝 Example: Finding the Vertex

Find the vertex of f(x) = 2x² - 8x + 3

Solution:

Given: a = 2, b = -8, c = 3

Step 1: Find h (x-coordinate)

h = -(-8)/(2·2) = 8/4 = 2

Step 2: Find k (y-coordinate)

k = 2(2)² - 8(2) + 3 = 8 - 16 + 3 = -5

Answer: The vertex is at point (2, -5)

Intercepts: Where the Parabola Crosses the Axes

📍 Y-Intercept

Definition: Where the parabola crosses the y-axis (when x = 0)

y-intercept = c

How to find it: Simply look at the constant term in your equation!

Example:

f(x) = 3x² - 5x + 7

Y-intercept = 7

Point: (0, 7)

📍 X-Intercepts (Roots/Zeros)

Definition: Where the parabola crosses the x-axis (when y = 0)

How to find them: Solve ax² + bx + c = 0

Methods:

  • Factoring
  • Quadratic formula
  • Completing the square

The Quadratic Formula

x = (-b ± √(b² - 4ac)) / (2a)

Number of X-Intercepts (Discriminant: b² - 4ac):

  • b² - 4ac > 0 → Two x-intercepts (crosses x-axis twice)
  • b² - 4ac = 0 → One x-intercept (touches x-axis at vertex)
  • b² - 4ac < 0 → No x-intercepts (doesn't touch x-axis)

🌟 Real-Life Example: Projectile Motion

A ball is thrown with height function h(t) = -16t² + 32t + 48

  • Y-intercept (48): Initial height when thrown (48 feet)
  • X-intercepts: When the ball hits the ground (h = 0)
  • Vertex: Maximum height of the ball

Real-World Application: Business Revenue

🏢 Business Problem

A company finds that their monthly revenue R (in thousands of dollars) depends on their advertising spending x (in thousands of dollars) according to:

R(x) = -2x² + 20x + 50

Questions to Answer:

1. What is the initial revenue with no advertising?

Solution: Find R(0) = c = 50

Answer: $50,000 initial revenue

2. How much should they spend on advertising for maximum revenue?

Solution: Find the vertex x-coordinate

h = -b/(2a) = -20/(2·(-2)) = -20/(-4) = 5

Answer: Spend $5,000 on advertising

3. What is the maximum revenue?

Solution: Find k = R(5)

R(5) = -2(5)² + 20(5) + 50

R(5) = -2(25) + 100 + 50 = -50 + 100 + 50 = 100

Answer: Maximum revenue is $100,000

Interpretation:

  • The parabola opens downward (a = -2 < 0)
  • This makes sense: too little advertising means less revenue, but too much advertising has diminishing returns
  • The vertex (5, 100) represents the optimal strategy

🎯 Key Takeaways

  • Quadratic functions create parabolas (U-shaped curves)
  • The coefficient a determines if the parabola opens up or down
  • The vertex is the turning point (maximum or minimum)
  • Understanding intercepts helps you sketch and analyze the graph
  • Quadratic functions model many real-world situations: projectile motion, business optimization, and more!
