Exponential and Logarithmic Functions

An exponential function answers "how big does it get?" A logarithm answers the reverse question, "how long did it take?" This lecture builds both ideas, introduces the number e, and ends with solving equations that contain ex, log x and ln x.

Part 1

Exponential functions

A linear function adds the same amount at every step: 3, 5, 7, 9. An exponential function multiplies by the same amount at every step: 3, 6, 12, 24. That one change is the difference between a salary that rises by $2,000 a year and one that rises by 5% a year.

The formula is f(x) = a · bx. The number a is the starting value, which is where the graph crosses the y-axis. The number b is the growth factor, the number you multiply by each time x goes up by 1. If b is greater than 1 the function grows. If b is between 0 and 1 it decays.

Part 2

The number e and the function ex

Put $1 in a bank that pays 100% interest per year. If the interest is added once, you end the year with $2. If the bank pays 50% twice, you get 1.5 × 1.5 = $2.25, because the second payment earns interest on the first. Paying more often keeps helping, but less and less each time.

The balance never passes a certain ceiling. That ceiling is the number e ≈ 2.71828. Like π, it is irrational, and it shows up whenever something grows continuously in proportion to its own size: money, populations, radioactive decay, cooling coffee.

The function f(x) = ex is called the natural exponential function. It is an ordinary exponential function whose base happens to be e, so everything from Part 1 still applies.

Part 3

Logarithms: log and ln

An exponential asks "2 to the 3rd power is what?" A logarithm asks the question backwards: "2 to what power is 8?" The answer is 3, and we write log2 8 = 3. A logarithm is an exponent.

In general, logb x = y means the same thing as by = x. Two bases are used so often that they get short names. log x with no base written means base 10. ln x means base e, and is called the natural logarithm.

Because the logarithm undoes the exponential, the two are inverse functions. Their graphs are mirror images across the line y = x, and their x and y roles are swapped: the exponential takes any x and gives a positive output, so the logarithm only accepts positive inputs and gives any output.

What you cannot do. No power of a positive base is ever zero or negative, so log 0 and log(−5) are undefined. The inside of a logarithm must be positive. The graph has a vertical asymptote at x = 0 and always passes through (1, 0).

Part 4

Properties of logarithms

Logarithms are exponents, so they follow the exponent rules. When you multiply powers of the same base you add the exponents, which means the log of a product is the sum of the logs. Division becomes subtraction, and a power becomes multiplication.

This is why logarithms were invented. Before calculators, people multiplied huge numbers by adding their logs. You will use the same rules to pull a variable out of an exponent.

Part 5

Solving exponential and logarithmic equations

Exponentials and logarithms undo each other, and that is the whole method. If the unknown is stuck in an exponent, take a logarithm of both sides to bring it down. If the unknown is stuck inside a logarithm, rewrite the equation as a power to get it out.

Exponential equations. First isolate the exponential part. Then take ln of both sides (or log, either works). Then solve what is left.

Logarithmic equations. First combine everything into a single logarithm. Then rewrite in exponential form. Then solve, and check every answer in the original equation, because the inside of a logarithm must be positive.

The solution is where the curve meets the line

Undo an exponentialex = c  →  x = ln c
Undo a logarithmln x = c  →  x = ec
Any basebx = c  →  x = {{ln c|ln b}}
One-to-onelog A = log B  →  A = B

Before you reach for a calculator. If both sides can be written as powers of the same base, set the exponents equal and skip the logarithm. And an equation like ex = −3 has no solution, because ex is always positive.
