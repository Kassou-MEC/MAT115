🔄 Inverse Functions

From One-to-One Functions to Finding Inverses

Introduction to Inverse Functions

What is an Inverse Function?

An inverse function "undoes" what the original function does. If a function f takes an input x and produces output y, then the inverse function f⁻¹ takes y as input and produces x as output.

If f(x) = y, then f⁻¹(y) = x

Real-World Analogy

Think of a function as a machine that converts Celsius to Fahrenheit:

  • Function: You put in 0°C and get 32°F
  • Inverse: You put in 32°F and get back 0°C
Example 1: Simple Function Pairs

Consider the function f(x) = x + 3

f(2) = 2 + 3 = 5

The inverse function f⁻¹(x) = x - 3 "undoes" this:

f⁻¹(5) = 5 - 3 = 2

Notice: f⁻¹(f(2)) = f⁻¹(5) = 2 ✓

Key Property: For a function and its inverse:
f(f⁻¹(x)) = x AND f⁻¹(f(x)) = x

One-to-One Functions

Definition

A function is one-to-one (injective) if different inputs always produce different outputs.

If x₁ ≠ x₂, then f(x₁) ≠ f(x₂)

Equivalently: If f(x₁) = f(x₂), then x₁ = x₂

Why Do We Need One-to-One Functions?

Only one-to-one functions have inverses! If two different inputs produce the same output, the inverse wouldn't know which input to return.

Example 2: One-to-One Function

Function: f(x) = 2x + 1

Test: Let's check if it's one-to-one

Step 1: Assume f(x₁) = f(x₂)
Step 2:
2x₁ + 1 = 2x₂ + 1
Step 3:
2x₁ = 2x₂
Step 4:
x₁ = x₂

Conclusion: Since f(x₁) = f(x₂) implies x₁ = x₂, the function IS one-to-one! ✓

Example 3: NOT One-to-One

Function: f(x) = x²

Test: Let's check different inputs

f(2) = 2² = 4
f(-2) = (-2)² = 4

Conclusion: Different inputs (2 and -2) produce the same output (4), so this is NOT one-to-one! ✗

Horizontal Line Test

The Horizontal Line Test

A function is one-to-one if and only if no horizontal line intersects its graph more than once.

How to Use the Horizontal Line Test

  1. Draw the graph of the function
  2. Imagine drawing horizontal lines across the graph at various y-values
  3. If ANY horizontal line touches the graph more than once, it's NOT one-to-one
  4. If EVERY horizontal line touches at most once, it IS one-to-one
Example 4: Applying the Horizontal Line Test

Function: f(x) = x³ - 3x

Move the horizontal line: y = 0

Notice: Some horizontal lines cross the graph multiple times! This function is NOT one-to-one.

Example 5: One-to-One by HLT

Function: f(x) = 2x + 3

Move the horizontal line: y = 0

Every horizontal line crosses exactly once! This function IS one-to-one. ✓

Remember:
  • Horizontal Line Test checks if a function is one-to-one
  • Vertical Line Test checks if a relation is a function
  • A function must pass BOTH tests to have an inverse that is also a function

Finding Inverses: Linear Functions

General Steps to Find an Inverse

Step 1: Replace f(x) with y
Step 2: Swap x and y
Step 3: Solve for y
Step 4: Replace y with f⁻¹(x)
Example 6: Simple Linear Function

Find the inverse of: f(x) = 3x + 2

Step 1: Write as y = 3x + 2
Step 2: Swap x and y: x = 3y + 2
Step 3: Solve for y:
x = 3y + 2
x - 2 = 3y
y = (x - 2)/3
Step 4: The inverse is: f⁻¹(x) = (x - 2)/3
Verification: Let's check f(f⁻¹(x)) = x
f(f⁻¹(x)) = f((x-2)/3) = 3·((x-2)/3) + 2 = (x-2) + 2 = x ✓
Example 7: Linear with Fraction

Find the inverse of: f(x) = (2x - 5)/4

Step 1: Write as y = (2x - 5)/4
Step 2: Swap x and y: x = (2y - 5)/4
Step 3: Solve for y:
x = (2y - 5)/4
4x = 2y - 5
4x + 5 = 2y
y = (4x + 5)/2
Step 4: The inverse is: f⁻¹(x) = (4x + 5)/2
Example 8: Negative Slope

Find the inverse of: f(x) = -2x + 7

Step 1: y = -2x + 7
Step 2: x = -2y + 7
Step 3:
x = -2y + 7
x - 7 = -2y
y = (7 - x)/2 or y = -x/2 + 7/2
Step 4: The inverse is: f⁻¹(x) = (7 - x)/2

Finding Inverses: Odd Power Functions

Why Odd Powers?

Functions with odd powers (x³, x⁵, x⁷, etc.) are one-to-one across all real numbers because they maintain the same sign as their input.

(-2)³ = -8 and (2)³ = 8 (different outputs!)
⚠️ Even Powers: Functions like f(x) = x² are NOT one-to-one over all reals because f(-2) = f(2) = 4. We need to restrict the domain to make them one-to-one.
Example 9: Cube Function

Find the inverse of: f(x) = x³

Step 1: y = x³
Step 2: x = y³
Step 3:
x = y³
³√x = y (take the cube root of both sides)
Step 4: The inverse is: f⁻¹(x) = ³√x = x^(1/3)
Example 10: Scaled Cube Function

Find the inverse of: f(x) = 2x³ + 3

Step 1: y = 2x³ + 3
Step 2: x = 2y³ + 3
Step 3:
x = 2y³ + 3
x - 3 = 2y³
(x - 3)/2 = y³
y = ³√((x - 3)/2)
Step 4: The inverse is: f⁻¹(x) = ³√((x - 3)/2)
Example 11: Fifth Power

Find the inverse of: f(x) = (x - 1)⁵ + 4

Step 1: y = (x - 1)⁵ + 4
Step 2: x = (y - 1)⁵ + 4
Step 3:
x = (y - 1)⁵ + 4
x - 4 = (y - 1)⁵
⁵√(x - 4) = y - 1
y = ⁵√(x - 4) + 1
Step 4: The inverse is: f⁻¹(x) = ⁵√(x - 4) + 1

f⁻¹(x) = ⁿ√((x - b)/a)

Finding Inverses: Rational Functions

Rational Functions

A rational function where both numerator and denominator are linear has the form:

f(x) = (ax + b)/(cx + d)

These require careful algebraic manipulation to find inverses.

Example 12: Simple Rational

Find the inverse of: f(x) = (x + 1)/(x - 2)

Step 1: y = (x + 1)/(x - 2)
Step 2: x = (y + 1)/(y - 2)
Step 3: Solve for y (multiply both sides by (y - 2)):
x(y - 2) = y + 1
xy - 2x = y + 1
xy - y = 2x + 1
y(x - 1) = 2x + 1
y = (2x + 1)/(x - 1)
Step 4: The inverse is: f⁻¹(x) = (2x + 1)/(x - 1)
Example 13: Rational with Coefficients

Find the inverse of: f(x) = (3x - 2)/(x + 4)

Step 1: y = (3x - 2)/(x + 4)
Step 2: x = (3y - 2)/(y + 4)
Step 3:
x(y + 4) = 3y - 2
xy + 4x = 3y - 2
xy - 3y = -4x - 2
y(x - 3) = -4x - 2
y = (-4x - 2)/(x - 3)
y = -(4x + 2)/(x - 3)
Step 4: The inverse is: f⁻¹(x) = -(4x + 2)/(x - 3)
Example 14: Another Rational

Find the inverse of: f(x) = (2x + 5)/(3x - 1)

Step 1: y = (2x + 5)/(3x - 1)
Step 2: x = (2y + 5)/(3y - 1)
Step 3:
x(3y - 1) = 2y + 5
3xy - x = 2y + 5
3xy - 2y = x + 5
y(3x - 2) = x + 5
y = (x + 5)/(3x - 2)
Step 4: The inverse is: f⁻¹(x) = (x + 5)/(3x - 2)

Key Strategy for Rational Functions

  1. After swapping x and y, multiply both sides by the denominator
  2. Distribute to eliminate parentheses
  3. Collect all terms with y on one side
  4. Factor out y
  5. Divide to isolate y
Domain Restrictions: For rational functions, always note:
  • The denominator cannot equal zero
  • Values that make the denominator zero are excluded from the domain
  • For f(x) = (3x-2)/(x+4), the domain is all reals except x = -4

🎯 Test Your Skills!
Problem 1: Find the inverse of f(x) = 4x - 7
Hint: Start with y = 4x - 7, swap to get x = 4y - 7, then solve for y. Add 7 to both sides, then divide by 4.
Problem 2: Find the inverse of f(x) = (x - 3)/5
Hint: After swapping: x = (y - 3)/5. Multiply both sides by 5, then add 3.
Problem 3: Find the inverse of f(x) = x³ - 5
Hint: After swapping: x = y³ - 5. Add 5 to both sides, then take the cube root.
Problem 4: Is f(x) = x² + 4 one-to-one over all real numbers? (yes/no)
Hint: Think about f(2) and f(-2). Do they give the same output?
Problem 5: Find the inverse of f(x) = (2x + 1)/(x - 3)
Hint: After swapping: x = (2y + 1)/(y - 3). Multiply both sides by (y - 3), expand, collect y terms on one side, and factor.
Problem 6: Find the inverse of f(x) = 3x³ + 2
Hint: Subtract 2, divide by 3, then take the cube root.
Problem 7: If f(x) = 2x - 5 and g(x) is the inverse of f, what is g(7)?
Hint: First find the inverse: g(x) = (x + 5)/2. Then calculate g(7).
Problem 8: Find the inverse of f(x) = -3x + 9
Hint: After swapping: x = -3y + 9. Subtract 9, then divide by -3. Can also write as -x/3 + 3.
Problem 9: Find the inverse of f(x) = (x + 2)⁵ - 1
Hint: Add 1, take the fifth root, then subtract 2.
Problem 10: Find the inverse of f(x) = (5x - 3)/(2x + 1)
Hint: After x(2y + 1) = 5y - 3, expand and collect y terms: 2xy - 5y = -x - 3, then factor and divide.

Summary & Key Takeaways

Essential Concepts

Concept Definition Test/Method
Inverse Function f⁻¹ "undoes" f: if f(a) = b, then f⁻¹(b) = a f(f⁻¹(x)) = x and f⁻¹(f(x)) = x
One-to-One Different inputs → different outputs If f(x₁) = f(x₂), then x₁ = x₂
Horizontal Line Test Visual check for one-to-one Each horizontal line crosses at most once

Steps to Find an Inverse

1. Replace f(x) with y
2. Swap x and y
3. Solve for y
4. Replace y with f⁻¹(x)
5. Verify (optional but recommended)
Quick Reference: Common Inverses
Function Type Example Inverse
Linear f(x) = ax + b f⁻¹(x) = (x - b)/a
Cube f(x) = x³ f⁻¹(x) = ³√x
Scaled Cube f(x) = ax³ + b f⁻¹(x) = ³√((x-b)/a)
Simple Rational f(x) = a/x f⁻¹(x) = a/x (self-inverse!)

Important Properties

  • Composition: (f ∘ f⁻¹)(x) = (f⁻¹ ∘ f)(x) = x
  • Domain & Range: Domain of f = Range of f⁻¹, and vice versa
  • Graphs: f and f⁻¹ are reflections across the line y = x
  • Uniqueness: If an inverse exists, it's unique

Common Mistakes to Avoid

  1. Forgetting to swap x and y
  2. Not checking if the function is one-to-one first
  3. Arithmetic errors when solving for y
  4. Confusing f⁻¹(x) with 1/f(x)
  5. For rational functions: errors when multiplying by the denominator
Remember: f⁻¹(x) ≠ 1/f(x)

The notation f⁻¹(x) means the inverse function, NOT the reciprocal!

If f(x) = 2x, then:
• f⁻¹(x) = x/2 (inverse function)
• 1/f(x) = 1/(2x) (reciprocal)
